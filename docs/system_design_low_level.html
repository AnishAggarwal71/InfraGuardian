The only two gates that decide anything are "rule pre-screen" and "routing gate" — both pure logic, no model call. Everything between them is advisory input the gate consumes; it never bypasses the gate, and a failure anywhere upstream collapses to the same fail-closed severity rather than silently defaulting to an action.
